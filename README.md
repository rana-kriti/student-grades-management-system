# student-grades-management-system

A simple command-line based Student Grades Management System built in Python.
This project allows users to manage student records efficiently using a menu-driven interface.

## Features
- Add a new student record
- Update an existing student’s grade
- Delete a student record
- Search for a student
- View all student records
- View total number of students
- Interactive and user-friendly CLI interface
- Animated welcome message and menu display

## Technologies Used
- Python 3
- Built-in time module
- Dictionary data structure for storing student records
